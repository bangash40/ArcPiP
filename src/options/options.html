ArcPiP

Arc's mini player for Chrome. Playing videos pop out when you switch tabs and pop back in when you return.

Thanks for installing ArcPiP! Two quick steps below and you're set. Tabs that were already open may need a reload.

Setup

Checking your Chrome version…

  1. Allow "Automatic picture-in-picture" on your video sites

    Chrome asks for permission before a site may pop a video out on its own. For each site you use (YouTube, Twitch, Vimeo…):

    1. Open the site in a tab.
    2. Click the site information icon at the left end of the address bar .
    3. Find Automatic picture-in-picture and set it to Allow. If it isn't listed, open Site settings from the same menu and change it there.

    Alternatively, the first time a video pops out, Chrome shows a prompt. Choose to allow it on every visit. You can review all sites under Settings → Privacy and security → Site settings → Additional permissions → Automatic picture-in-picture.

  2. Play a video and switch tabs

    When ArcPiP is armed, the toolbar icon shows a PiP badge. Switch to another tab and the video floats above every app, even with Chrome minimized. Come back and it pops back in.

    Tip: pin ArcPiP from the puzzle-piece menu so you can see the badge.

Nothing pops out? Troubleshooting
  • The video must be playing with sound. Chrome only pops out media that was audible in the last couple of seconds. Muted or paused videos stay put.
  • It must be in the main page. Chrome doesn't auto-pop videos inside embedded iframes (for example a YouTube embed on a blog). Use Pop out now or the keyboard shortcut for those.
  • Permission. Make sure the site isn't set to Block for Automatic picture-in-picture (step 1). Without an explicit Allow, Chrome only allows sites you use often.
  • Older or staged rollouts. On Chrome 134+ the feature is normally on. If your browser doesn't have it, set chrome://flags/#auto-picture-in-picture-for-video-playback to Enabled and relaunch. Flag names can change between versions.
  • Tabs opened before install. Reload them once.
  • Shortcut doesn't work? Another extension may own Alt+P.

    How it works

    Chrome 134 added automatic picture-in-picture for media playback: if a page registers a Media Session enterpictureinpicture handler, Chrome calls it when you switch away from a tab with a playing, audible video. ArcPiP registers that handler on every site for the best video on the page, adds skip back/forward buttons to the PiP window, and closes the window when you come back. Site features like YouTube's next-video button keep working.

    ArcPiP has no servers, analytics or remote code. Settings sync through your Chrome profile.
